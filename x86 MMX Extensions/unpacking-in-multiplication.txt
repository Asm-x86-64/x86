#### Order of unpacking

Dest: word-3  word-2  word-1  word-0
Src: word-3  word-2  word-1  word-0

order for unpacking is source operand word-1 first and destination operand word-1 second (Higher 32-bits) and source operand word-0 first and destination operand word-1 second (lower-32bits)

After PUNPCKLWD:-

Dest:- word-1[src] word-1[Dest]  word-0[src] word-0[Dest]


So always the order should follow this syntax:-

PUNPCKLWD  <destination_operand> <source_operand>
PUNPCKHWD  <destination_operand> <source_operand>


destination_operand -> Should be the (lower-16-Bits) calculated from PMULLW Instruction, to get the correct result.
source_operand -> Should be the (Higher-16-Bits) calculated from PMULHW Instruction, to get the correct result.


So the, above syntax can be written as for easier understanding:-

PUNPCKLWD  <MMX_register_had_result_of_PMULLW> <MMX_register_had_result_of_PMULHW>
PUNPCKHWD  <MMX_register_had_result_of_PMULLW> <MMX_register_had_result_of_PMULHW>
